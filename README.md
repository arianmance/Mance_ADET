# Mance_ADET

Notely - Personal Note App

Notely is a clean and minimal Flutter-based mobile app designed to help users organize their thoughts and notes in a personal space. The app features a visually appealing UI with a device frame for preview, interactive menu, and structured pages for About, Menu, Contact, and Profile.

Features
Home Page: Welcome screen with app logo, tagline, and “Get Started” button.
About Page: Explains the app’s purpose and mission.
Menu Page: Interactive menu with “My Notes,” “Favorites,” and “Archive” options.
Contact Page: Contact information with clickable icons.
Profile Page: User profile section with options like “Edit Profile,” “Buy Premium,” and notifications.
Responsive UI: All pages fit perfectly inside an iPhone 13 device frame using the device_frame package.
Consistent Design: All pages have a unified background, rounded containers, and consistent typography.
